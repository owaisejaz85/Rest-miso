# MISO Restaurant Website

A responsive restaurant chain landing page built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page structure and content
- `style.css` — visual styling and responsive breakpoints
- `script.js` — mobile navigation, gallery controls and reservation form behaviour

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser.
3. Internet is required for Google Fonts and the remote Unsplash photography.

## Before using for a real restaurant
- Replace the demo MISO name, addresses, phone numbers and email with the client's real details.
- Replace the sample photography with licensed restaurant photos.
- Update the WhatsApp number in `script.js` (`whatsappNumber`).
- The reservation form currently opens WhatsApp. It does not store bookings in a database.
- Replace the sample menu button destination with a real menu page or PDF.
